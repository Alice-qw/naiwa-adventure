# 勇者奶蛙传：营救公主

一款以奶蛙为主角的独立网页小游戏，采用单文件 HTML 实现，包含游戏画面、样式和交互逻辑。

## 在线游玩

[打开游戏](https://alice-qw.github.io/naiwa-adventure/)

## 操作方式

- 电脑：WASD 或方向键移动；F 发射奶球；空格防御；E 大笑；V 奶蛋。
- 手机：使用画面下方的触控按键。

## 源码

游戏完整源码位于 [index.html](./index.html)。下载后用浏览器打开即可运行。

GitHub Pages 通过 [deploy-pages.yml](./.github/workflows/deploy-pages.yml) 自动发布；推送到 main 分支后会重新部署。
